# **App Name**: VendorTrack

## Core Features:

- Authentication: Firebase Authentication for user login/signup (email & password).
- Data Storage: Firestore database to store order, payment, and profit data.
- Data Privacy: Ensure users only see their own data (data isolation).
- Dashboard: Central hub for tracking key metrics like total orders, revenue, and profit margins.
- Order Management: Ability to track orders with details, due dates, payments, customer info, and special requests. Lets LLM tool create optimized routes based on deliveries in area, factoring traffic.

## Style Guidelines:

- Primary color: Deep blue (#2E3192) for trustworthiness and professionalism, reflecting the app's business focus.
- Background color: Very light blue (#EBF2FA), a desaturated version of the primary color for a clean, calming backdrop.
- Accent color: Violet (#736AB7), a brighter color analogous to deep blue, will provide visual interest in interactive elements and key information.
- Body and headline font: 'Inter' sans-serif font for a modern, machined, neutral look. Note: currently only Google Fonts are supported.
- Mobile-responsive layout for accessibility on various devices.
- Consistent use of minimalist icons for key actions and navigation.
